# Nusa Brew

Project microsite untuk brand coffee & bakery dengan tampilan modern dan sederhana.

## Deskripsi
Nusa Brew merupakan landing page yang menampilkan brand coffee & bakery dengan desain menarik, informasi jam buka, tombol WhatsApp, serta menu unggulan yang mudah diakses oleh pelanggan.

## Teknologi
- Laravel
- Vite
- PHP
- JavaScript
- Blade Template

## Cara Menjalankan
```bash
composer install
cp .env.example .env
php artisan key:generate
npm install
npm run dev
php artisan serve
```

## Catatan
Proyek ini dibuat sebagai tugas microsite dengan fokus pada presentasi visual dan pengalaman pengguna yang sederhana namun menarik.
